Mint with your AI agent

Zigzoo is agent-only: there is no mint button on this page. Give the prompt below to your AI agent (for example your Binance Agentic Wallet agent) and it will mint for you.

Don't have an AI agent yet?

  1. Install the Binance Wallet app (not the Binance exchange app).
  2. Activate the Agentic Wallet and claim your free Agent ID name (like name.ai).
  3. Copy the prompt below and paste it to your agent in the Binance Wallet app.
  4. Your agent shows a preview — confirm, and it mints for you.

How it works

  1. Your agent reads this page and the skill file (agent-skill.md).
  2. It checks the mint is open and your wallet holds a SPACE ID Agent ID.
  3. It reads the exact price for your next mint from the contract.
  4. It shows you a preview — including the exact price — and only mints after you confirm.
  5. It verifies the mint on-chain and tells you which animal you got.

Prompt for your agent

You are an AI agent minting a Zigzoo NFT for your user on BNB Smart Chain (chain 56). Read https://zigzoo.xyz/agent-skill.md and follow it exactly — it has the contract address, price ladder, checks and the mint flow. Show the user a preview with the exact price, and mint only after they confirm. Never mint without a SPACE ID Agent ID; never send more than priceFor().

Questions

When can I mint?
Now — minting is live. Ask your AI agent to mint for you; the first mint per wallet is free.
How much does it cost?
Your first mint is free. After that the price rises per wallet: 0.0002, 0.0004, then 0.0008 BNB. See the price ladder above.
How is the animal chosen?
Every mint draws the next token from a shuffled deck, recorded on-chain as a deck hash. The draw is random by deck order, not by choice — your animal is a surprise.
Can I mint from a browser wallet?
No. Minting is agent-only by design: only a wallet holding a SPACE ID Agent ID can mint, and the mint must be made by an AI agent for its user.
Where do I see my NFT after minting?
Use Check a wallet below the mint prompt — paste your wallet address to see your NFTs, mint count and next price. Or look up one NFT by its token number on the Check your NFT page.
What if my agent says I don't have an Agent ID?
Claim a free Agent ID in the Binance Wallet app — see “Don't have an AI agent yet?” above — then ask your agent to try again.
