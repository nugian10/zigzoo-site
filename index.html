Mint with your AI agent

Zigzoo is agent-only: there is no mint button on this page. Give the prompt below to your AI agent (for example your Binance Agentic Wallet agent) and it will mint for you when the contract is live.

How it works

  1. Your agent reads this page and the skill file (agent-skill.md).
  2. It checks the mint is open and your wallet holds a SPACE ID Agent ID.
  3. It reads the exact price for your next mint from the contract.
  4. It shows you a preview — including the exact price — and only mints after you confirm.
  5. It verifies the mint on-chain and tells you which animal you got.

Prompt for your agent

You are an AI agent minting a Zigzoo NFT for your user on BNB Smart
Chain (chain 56). Zigzoo: 5,000 ERC-721 (ZIGZOO), agent-only,
max 30 mints per wallet.

CONTRACT: NOT DEPLOYED YET. Address:
0x0000000000000000000000000000000000000000 (placeholder). Do NOT mint
until https://zigzoo.xyz/ shows a real contract address.

WHEN LIVE:
- Only a wallet holding a SPACE ID Agent ID can mint (registry
  0x60B9262456dE011F7d15a54CdD8c48bAaa8B022F; the contract checks
  holdsAgentId on-chain). Contract calls are rejected.
- mint() takes NO arguments and mints 1 NFT per call.
- Price per wallet: #1 FREE, #2-10: 0.0002 BNB, #11-20: 0.0004 BNB,
  #21-30: 0.0008 BNB (max total 0.0138 BNB). Read priceFor(your wallet)
  for the exact price — never hardcode it.

FLOW, per mint:
1. Read mintActive() and totalSupply(). If 5000, sold out; if
   mintActive is false, not open yet.
2. Read holdsAgentId(your wallet). If false, the wallet cannot mint.
3. Read mintCount(your wallet). If 30, the wallet is at its limit.
4. Read priceFor(your wallet) — the exact value to send.
5. Preview:
   baw contract-call preview --binanceChainId 56 --from <agentic wallet> --to <contract> --value <priceFor in wei> --inputData 0x1249c58b --json
6. Show the preview to the user. Execute with the preview's requestId
   only after they confirm.
7. Verify: totalSupply() and mintCount() each rose by 1; read
   tokenURI(new tokenId) and report the animal.

Never mint without an Agent ID; never send more than priceFor().

Questions

When can I mint?
Not yet — the contract is being deployed. This page will show the real contract address and the mint status as soon as it is live.
How much does it cost?
Your first mint is free. After that the price rises per wallet: 0.0002, 0.0004, then 0.0008 BNB. See the price ladder above.
How is the animal chosen?
Every mint draws the next token from a shuffled deck, recorded on-chain as a deck hash. The draw is random by deck order, not by choice — your animal is a surprise.
Can I mint from a browser wallet?
No. Minting is agent-only by design: only a wallet holding a SPACE ID Agent ID can mint, and the mint must be made by an AI agent for its user.
